# 中医推拿机械臂科普展示

本项目面向公众介绍中医推拿需求、手臂穴位相对定位、按摩头与机械臂结构、3D打印样品及两种装配成品、免 MATLAB 三维运动仿真，以及力度控制和项目证据。

## 在线页面

- `index.html`：主科普宣传页，包含调查报告、结构设计、运动仿真、安全边界与科普自测。
- `互动展厅.html`：无需 MATLAB 的三维互动展示，可切换指压、指揉、指振并调节力度。
- `真实轨迹预览.html`：导入的 robotarm2 机械臂模型与 MATLAB 计算轨迹。
- `reports/`：项目调查报告与电脑仿真说明全文。

## 数据与边界

- 公众需求部分基于 204 份有效问卷的统计结果。
- 穴位相对坐标为便于科普展示建立的前臂比例模型，不替代中医临床取穴。
- 当前成果为原理样机与电脑仿真，尚未完成整机人体安全性和临床疗效验证。
- 本页面不构成医疗器械说明，也不提供诊断、治疗或疗效承诺。

## 使用说明

推荐通过 GitHub Pages 访问。三维互动展厅需要支持 WebGL 的现代浏览器，首次加载完整 STL 与轨迹数据时可能需要数秒。

第三方组件和素材使用范围见 `第三方许可说明.txt`。公开使用前，请由项目指导教师复核穴位资料图的来源与授权。
